# John Charles Omagap — Portfolio

An Engineering Field Notes portfolio for a BS Computer Science student documenting practical work in web development,
automation, data review, and technical troubleshooting while building cybersecurity foundations.

## What the site presents

- Three featured projects with unequal hierarchy and outcome-first summaries.
- A sanitized interface capture for the archived Too Many Chats SillyTavern extension.
- Real STICA application captures from an isolated local demo with visibly synthetic records.
- Public-safe case studies for student-operations automation and a 10,000+-record human-in-the-loop audit.
- Assistance and verification notes that distinguish AI-supported work from John Charles's decisions and checks.
- Explicit maintenance, privacy, reconstruction, and limitation labels.
- Verified EF SET C1 Advanced English and seminar-attendance credentials as supporting evidence.

## Design approach

- An editorial evidence-notebook theme using self-hosted Newsreader and IBM Plex typography.
- Field-note labels, numbered records, and restrained light/dark stages that connect claims to evidence.
- Sticky project storytelling on desktop and a normal linear reading order on smaller screens.
- Progressive masked reveals, subtle scroll-driven depth, and same-origin view transitions.
- Semantic HTML, keyboard-visible focus states, reduced-motion support, and responsive navigation.
- A complete static fallback when JavaScript or advanced CSS features are unavailable.
- Static HTML, CSS, and JavaScript with no framework or build step.
- A visual `design-history.html` timeline built from captures rendered from preserved Git milestones.

## Curated local history

The local curation branch connects the original React source and GitHub Pages histories to a concise set of v2 design milestones. Annotated tags identify the v1 source, v1 deployment, initial v2, terminal v2, deployed editorial v2, and the current local release candidate. The original public history and the pre-curation working tree remain available through local archive branches.

No rewritten branch or tag is pushed automatically. The repository owner must review the graph and explicitly approve any future force-with-lease update.

## Media and video readiness

Project media uses a reusable browser-style frame with fixed dimensions and poster-first presentation. Production video
is intentionally deferred until either Too Many Chats or STICA can be reproduced with a sanitized local demo. Future
clips should be short, audio-free, user-initiated, and supplied as WebM plus MP4 with a matching poster image.

## Privacy approach

The public case studies use aggregate metrics and synthetic examples. They do not publish class transcripts, course
announcements, task content, account identifiers, private server data, credentials, or raw automation configuration.
The Too Many Chats capture preserves the implemented interface while replacing private chat content with synthetic
placeholders.

## AI assistance and cybersecurity direction

AI tools support parts of research, integration, drafting, and troubleshooting. The portfolio separates that assistance
from the requirements John Charles defined, the decisions he made, and the behavior or records he personally reviewed.
Available evidence and unresolved limitations are stated alongside each case study rather than treating an agent's
completion message as proof.

The current positioning is security-minded engineering, not a claim of professional cybersecurity experience. Future
security labs and write-ups can extend the Field Notes structure as John Charles develops verifiable cybersecurity work.
